CultureKart - Quick Start Guide

Simple guide to install dependencies and run the project.



Prerequisites

Ensure you have installed
- Node.js v22.14.0 or higher ([Download here](httpsnodejs.org))
- npm v10.9.2 or higher (comes with Node.js)

Verify installation
powershell
node --version
npm --version

Pull from GitHub Repo or Download as Zip from 
https://github.com/tech-Hussain/CultureKart

Step 1 Install Dependencies

Backend
open powershell in CultureKart root folder
run
cd backend
npm install

Wait 2-3 minutes for installation to complete.

Frontend
open powershell in CultureKart root folder
run
cd frontend
npm install

Wait 3-5 minutes for installation to complete.

Smart Contract
open powershell in CultureKart root folder
run
cd contracts
npm install

Wait 1-2 minutes for installation to complete.


Step 2 Run the Project

Open Three Terminals

Terminal 1 - Start Backend
open powershell in CultureKart root folder
run
cd backend
npm run dev

Backend will run at `http://localhost:5000`

Terminal 2 - Start Frontend
open powershell in CultureKart root folder
run
cd frontend
npm run dev

Frontend will run at `http://localhost:5173`

Terminal 3 - Start Stripe Webhook (for payment testing)
open powershell in CultureKart root folder
run
cd stripe-cli ; .\stripe.exe listen --forward-to localhost:5000/api/v1/stripe/webhook

Stripe webhook listener will connect and show webhook signing secret.


Step 3 Access the Application

Open your browser and go to

http://localhost:5173

Quick Checklist

- Node.js installed
- Backend dependencies installed (`npm install` in backend)
- Frontend dependencies installed (`npm install` in frontend)
- Contracts dependencies installed (`npm install` in contracts) - Optional
- .env files present in backend and frontend
- Backend running on port 5000
- Frontend running on port 5173
- Stripe webhook listener running (for payment testing)
- Application accessible at http://localhost:5173



That's it! You're ready to explore CultureKart.
