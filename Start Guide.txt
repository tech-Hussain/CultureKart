CultureKart - Quick Start Guide

Simple guide to install dependencies and run the project.

---

## Prerequisites

Ensure you have installed
- Node.js v22.14.0 or higher ([Download here](httpsnodejs.org))
- npm v10.9.2 or higher (comes with Node.js)

Verify installation
```powershell
node --version
npm --version
```

---

## Step 1 Install Dependencies

### Backend
```powershell
cd backend
npm install
```
Wait 2-3 minutes for installation to complete.

### Frontend
```powershell
cd ..frontend
npm install
```
Wait 3-5 minutes for installation to complete.

### Smart Contracts (Optional)
```powershell
cd ..contracts
npm install
```
Wait 1-2 minutes for installation to complete.

---

## Step 2 Run the Project

### Open Three Terminals

Terminal 1 - Start Backend
```powershell
cd backend
npm run dev
```
Backend will run at `httplocalhost5000`

Terminal 2 - Start Frontend
```powershell
cd frontend
npm run dev
```
Frontend will run at `httplocalhost5173`

Terminal 3 - Start Stripe Webhook (for payment testing)
```powershell
cd stripe-cli
.stripe.exe listen --forward-to localhost5000apiv1stripewebhook
```
Stripe webhook listener will connect and show webhook signing secret.

---

## Step 3 Access the Application

Open your browser and go to
```
httplocalhost5173
```

## Troubleshooting

### If backend fails to start
```powershell
# Check if .env file exists
ls backend.env

# Verify MongoDB connection string is set
```

### If frontend fails to start
```powershell
# Clear and reinstall
cd frontend
Remove-Item -Recurse -Force node_modules
npm install
npm run dev
```

### Port already in use
```powershell
# Kill process on port 5000
netstat -ano  findstr 5000
taskkill PID PID_NUMBER F
```
